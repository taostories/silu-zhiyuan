# 丝路知远

以丝绸之路为主题的网页剧情互动游戏。跟随旧画册走过长安、武威、敦煌与阿拉山口，完成四段体验。

在线游玩：https://taostories.github.io/silu-zhiyuan/

点击进入游戏开始，进度保存在当前浏览器。网页适配电脑和手机，右上音符可调整音乐。静态页面，无需构建，使用 GitHub Pages 从 main 分支根目录发布。

背景音乐：“Ripples” — Kevin MacLeod (incompetech.com)，CC BY 4.0。完整署名和许可见《背景音乐授权.md》。鼓铃样本来自 VSCO 2 CE，CC0，见 assets/audio/音效来源.md 与 LICENSE-CC0.txt。

游戏代码与交互由 OpenAI Codex 辅助制作；图片为作者提供的生成素材，经裁切、去底及排版处理。第三方音乐和音源各自遵循其许可。其他游戏内容及图像未在本仓库授予额外复用许可。
